# Demo videos

Every build ends with a short screen recording (decision 3 in [CURRENT_STATE.md](../CURRENT_STATE.md)). This folder holds one record per video: the business problem, what the video proves, the shot list, what must never appear, and the claim limits. From DEMO-02 on, the record is written **before** recording, so the recording follows a plan.

**How this connects to marketing:** this public folder holds the facts. The title, keywords, voice-over script, edit notes, and publishing status live in Josh's private marketing repository (`scripts/`), which reads this folder directly. Nothing is copied between the two; each marketing script page links to its record here.

## New record checklist

Copy the headings from DEMO-01. Before recording, fill in: the business problem, what it proves, the shot list (on screen, proof to see), must never appear, claim limits, and the re-shoot setup. Each record also carries a plain name and the script (a first-draft voice-over), so Josh only has to record. No file names or timestamps needed afterward.
